## Contributing

Contributions are welcome. The project is intentionally simple with minimal dependencies. Before submitting changes, consider whether the addition aligns with that philosophy.

### What needs work

- Better error handling for malformed pattern files
- CLI argument parsing (year, config overrides, dry-run mode)
- Cross-platform path handling
- Documentation improvements

### Guidelines

- Keep the script readable and self-contained
- Avoid adding external dependencies
- Test with a small pattern before submitting
- Ensure commit dates remain correct

### Submitting

1. Fork the repository
2. Create a branch with a descriptive name
3. Open a pull request explaining the change
